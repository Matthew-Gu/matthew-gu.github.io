### HybridBridge

**项目简介**
设计并实现了一个轻量级 H5 与原生（Android/iOS）双向通信桥接库，支持消息发送、事件监听及带超时的请求-响应模式，适用于混合开发（Hybrid App）场景，已在实际项目中稳定运行。

**技术栈**
TypeScript、JavaScript、WebView 通信机制、Android WebView（@JavascriptInterface）、iOS WKWebView（Script Message Handler）

**核心亮点**

- 实现统一 API 抽象，自动兼容 Android 与 iOS 平台，屏蔽原生差异
- 支持异步请求-响应模式（类 RPC），内置超时控制与 requestId 机制，保障通信可靠性
- 提供事件订阅/取消接口（on/off），支持原生主动推送消息，避免轮询开销
- 内置安全解析逻辑，自动处理无效 JSON、空值等边界情况，提升健壮性
- 轻量无依赖，可无缝集成至 Vue、React 等主流前端框架项目中
